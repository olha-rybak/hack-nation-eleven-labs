How the apprentice works, end to end

One local model does all the seeing and thinking, primed beforehand by a config folder about the app. ElevenLabs handles the voice. The expert's session becomes a Work Map, and the Work Map becomes a tutor. Tap any box to jump to its description.

Capture the expert works, the apprentice asks why

Environment config

C

A folder about the app: what it is, a glossary of every field, the rules that are already written down, a few captioned screenshots and today's task. At session start the model reads it once and writes an environment brief that stays in its context, so it names fields correctly and only asks about what the docs leave out.

Expert's screen

A

The fake ERP in a browser tab, shared with the apprentice. The expert processes real-looking invoices and talks while working.

Frame sampler

A

Grabs one screenshot per second, saves every frame with its timestamp, and forwards only frames that actually changed.

Pause detector

A

Waits for a still screen (4 s) and silence (3 s), with a 60 s cooldown and at most 5 questions. Then it tells the agent: ask now.

Nemotron Omni

B

The one model, running locally in llama-server with two slots. It turns frame changes into events like cost center 4711 → 0400, and writes every reply the agent speaks from the latest frames and event log.

ElevenLabs agent

C

Handles the voice: speech-to-text, turn-taking and the spoken reply. It sends each turn to our proxy, which calls Nemotron, and stays quiet while the expert narrates.

Expert's voice

expert

The expert's answers in their own words. These quotes become the reasons and guardrails in the Work Map.

Session log

B

Everything from the session on disk: events, timestamped transcript and saved frames. Off-the-record deletes the last 30 seconds here.

Map the session becomes a confirmed process

Debrief

C

After the expert clicks End task, the agent asks the 3+ questions it still has, then explains the whole process back until the expert says yes, that is how it works.

Work Map

B + A

Steps, decisions, reasons and guardrails, each tied to a screen frame and a quote. Shown as a clickable timeline and exported as an Obsidian vault.

Teach the Work Map coaches the next person

Tutor

C

The same capture loop on the new hire's screen, with the Work Map loaded. It checks every event against the guardrails, steps in before a wrong save and replays the expert's frame.

Progress report

A

What the new hire did right, which guardrails they hit, and what to practice next.
