# Screen: Return requests (return-requests.png)

The start screen, the queue of open cases. Columns from left to right: Return, Customer (name and
city), Item (product and order number), Reason, Delivered (date and "N days ago"), Price, Status.
Tabs above the table: "To process (5)" and "All (5)". The left sidebar shows "Return requests" with
the number of open cases. Clicking a row opens that case.
