# T-500 · Demo script + dry runs
**Lane C · owner: Olha · depends on: T-109, T-204, T-303**

The demo is the deliverable. Write and rehearse the run from the brief's *What Good Looks Like*:

1. A judge plays Sabine, shares their screen, processes three invoices while narrating.
2. At a pause the agent asks about the capex move; the judge explains the €5,000 line.
3. Debrief asks about the held December invoice and who releases it; teach-back under a minute; the judge
   corrects one detail.
4. Work Map: seven steps, three judgment calls, four guardrails, each linked to a screen moment.
5. A second judge plays the new hire on INV-4474, reaches for opex, and the tutor stops them.

Rehearse end to end at least three times with different people. Record a fallback video of a complete run
— a cold model, a dropped tunnel or a slow first token should never cost the demo.

Keep a one-page answer to each of the five Apprentice Test questions, with the file or screen that proves
it. Judges ask them directly.

**Acceptance:** three consecutive clean dry runs, and a recorded fallback.
