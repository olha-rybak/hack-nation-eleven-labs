# T-600 · Obsidian vault export
**Lane B · stretch · owner: Hlib · depends on: T-200**

Export a confirmed Work Map as an Obsidian vault: one note per step, one per guardrail, frames as
attachments, `[[wikilinks]]` from steps to the guardrails that govern them, and an index note that is the
process overview.

This is in the pipeline diagram as part of the Work Map node, and it is the cheapest way to make the
output feel like something a company keeps rather than a demo artifact — the knowledge outlives the app.

**Acceptance:** the exported folder opens in Obsidian with a working graph view, and every step note shows
its frame and quote.
